# A740 A7xx 单 draw 状态映射（#3d-1）

- 日期：2026-11-15
- 来源：`build/fuxi-tools/a740-draw-payload-r367.h`（r367/r369 通过的 submit00002 单 draw 捕获，8 个 BO / 1 个 IB）
- 目的：拆解 Turnip 在 A740 上生成的 3D draw 状态，作为 #3d 自生成命令流的输入清单；本文只做静态映射，不运行 GPU。
- 组 ID 语义来自 Turnip：`research/mesa-rd/src/freedreno/vulkan/tu_cmd_buffer.h:24-52`（`tu_draw_state_group_id`）和 `research/mesa-rd/src/freedreno/vulkan/tu_pipeline.h:20-36`（`tu_dynamic_state`）。这不是 Gallium 的 `fd6_state_id`，两者枚举顺序不同。

## 1. 顶层

- 顶层 IB：`0x2003c000`，1376 B（344 words）。
- `CP_SET_DRAW_STATE` 头在 word 245：`0x7043805a` = opcode 0x43，count 0x5a=90 words。
- 90 words = 30 个条目，每项 3 words：`{flags/count, addr_lo, addr_hi}`。
- 25 个条目有非零地址；5 个条目地址为 0（禁用/空组）。
- Turnip 发射代码：`research/mesa-rd/src/freedreno/vulkan/tu_cmd_buffer.cc:1306-1310`，写 `COUNT(state.size) | enable_mask | GROUP_ID(id)`，再 `tu_cs_emit_qw(state.iova)`。
- PM4 头格式：`research/mesa-rd/src/freedreno/common/freedreno_pm4.h:47-70`（type4/type7）。
- 组内容包：`CP_CONTEXT_REG_BUNCH`（op 0x5c，type7，偶数个 reg/value）、type4 连续寄存器写、`CP_LOAD_STATE6_GEOM/FRAG`（op 0x32/0x34/0x36）。

## 4. 对 #3d-2 的最小生成顺序（推断）

1. 生成 `PROGRAM_CONFIG`（#0）和 `VS`/`VS_BINNING`（#1/#2）所需的 shader/config 状态；VS 组内 `CP_LOAD_STATE6_GEOM` 的 payload 指向 `0x20009b40`（VS）和 `0x20009c40`（VS_BINNING）。
2. 生成 `FS`（#8）的常量/描述符状态；再用 `CP_LOAD_STATE6_FRAG` 指向 FS shader 代码（当前捕获中在 `0x20008000+0x7fc` 可见一条 7-word 的 0x34 包，疑似 FS 常量而非 shader，需进一步确认）。
3. 生成 `VIEWPORT/SCISSOR/RAST/BLEND`（#19/#20/#21/#28）等动态状态，以及 `PRIM_MODE_GMEM`（#18）。
4. 最后发 `CP_DRAW_INDX_OFFSET`（嵌套 IB word 336：`0x70388003`，payload `0xd84, 1, 3`）并用 capture 的 target image/framebuffer 验证 red/black。

## 5. 注意事项

- 本映射只覆盖 submit00002 的 triangle dump；submit00000/00001 是 fill/compute，不作为 3D 生成基准。
- `CP_SET_DRAW_STATE` 条目里的地址是 GPU VA；直接重放时必须按原 iova 用 `BoAlloc+BoMap` 映射，不能只按 BO 顺序猜。
- 不能把 `fd6_state_id` 名称套到这张表上：Turnip 的 #7 是 VPC，不是 VBO；#18 是 PRIM_MODE_GMEM，不是 BLEND。
